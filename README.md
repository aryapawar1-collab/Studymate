# StudyMate — Study Material

A simple static website for organizing CCA 2 revision material.

## Features
- Subject-wise study cards
- Search across subjects/topics
- Study tips
- Responsive design
- GitHub Actions CI workflow
- Ready for deployment as a Render Static Site

## Deployment
For Render, choose **Static Site** and use:
- Build Command: leave empty
- Publish Directory: `.`
